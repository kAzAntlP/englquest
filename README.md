## 📖 О проекте

EngQuest - это веб-приложение для изучения английских слов через интерактивные флеш-карточки. Проект разработан как MVP (Minimum Viable Product) с фокусом на чистую архитектуру и пользовательский опыт.

### ✨ Ключевые возможности

- 🎴 **Интерактивные флеш-карточки** - переворот по клику с плавной анимацией
- 📊 **Управление состоянием** - отслеживание текущей карточки и прогресса
- 🎨 **Адаптивный дизайн** - оптимизирован для мобильных и десктопных устройств
- ⚡ **Быстрая загрузка** - благодаря Next.js App Router и оптимизации изображений

## 🛠 Технологии

- **Framework:** Next.js 16.4.6 (App Router)
- **UI Library:** React 19.3.0
- **Language:** TypeScript 5.x
- **Styling:** Tailwind CSS 4.3.3
- **Linting:** ESLint 9.x
